7,LMServer (added in v1.3.1)
7.1 Overview of LmServerAPI Interface
Example call
The use steps of this kind of function are as follows:
Step 1: User login
Step 2: Lock the control card
Step 3: Send communication data packet
(Step 4: Receive communication packets) Called as needed
Step 5: Unlock the control card
Step 6: Exit the login
Note: If the user needs to log in online for a long time, it is necessary to send heartbeat packets to the server regularly to maintain the long connection, and the longest interval between heartbeat packets is not more than 120 seconds. The interval time refers to the interval time between the application and LmServer without data exchange.
