# T2.2 - Implementación de Decoradores de Permisos

## Resumen de Implementación

Se han implementado tres decoradores de permisos en `src/auth.py` para controlar el acceso a endpoints basado en roles y asignaciones de recursos.

## Decoradores Implementados

### 1. `require_superadmin`

**Propósito**: Restringe el acceso solo a usuarios con rol `superadmin`.

**Implementación**:
```python
@require_superadmin
def admin_only_endpoint():
    # Solo superadmin puede acceder
    pass
```

**Funcionamiento**:
- Verifica autenticación del usuario
- Comprueba que el rol sea `superadmin`
- Retorna error 403 si no cumple los requisitos

### 2. `require_parking_access`

**Propósito**: Restringe el acceso a parkings específicos basado en asignaciones de usuario.

**Implementación**:
```python
@require_parking_access('parking_id')
def parking_endpoint(parking_id):
    # Solo usuarios asignados al parking pueden acceder
    pass
```

**Funcionamiento**:
- Verifica autenticación del usuario
- Superadmin tiene acceso a todos los parkings
- Usuarios normales deben tener asignación en `UserParking`
- Retorna error 403 si no tiene permisos

### 3. `require_panel_access`

**Propósito**: Restringe el acceso a paneles específicos basado en asignaciones de usuario.

**Implementación**:
```python
@require_panel_access('panel_id')
def panel_endpoint(panel_id):
    # Solo usuarios asignados al panel pueden acceder
    pass
```

**Funcionamiento**:
- Verifica autenticación del usuario
- Superadmin tiene acceso a todos los paneles
- Usuarios normales deben tener asignación en `UserPanel`
- Retorna error 403 si no tiene permisos
