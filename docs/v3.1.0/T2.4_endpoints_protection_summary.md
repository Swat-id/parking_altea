# T2.4 - Resumen de Protección de Endpoints

## Resumen de Implementación

Se han aplicado decoradores de permisos a los endpoints críticos del sistema, manteniendo algunos endpoints públicos para funcionalidad básica.

## Endpoints Protegidos

### **Endpoints de Administración (Solo Superadmin)**
- `GET /admin/users` - Listar usuarios
- `POST /admin/users` - Crear usuario
- `GET /admin/users/{id}` - Detalles de usuario
- `POST /admin/users/{id}/assign` - Asignar recursos
- `DELETE /admin/users/{id}` - Eliminar usuario
- `PUT /admin/users/{id}/role` - Cambiar rol
- `POST /admin/users/{id}/toggle` - Activar/desactivar
- `POST /schedules` - Crear programaciones

### **Endpoints de Parking (Acceso por Asignación)**
- `POST /parking/{pid}/occupancy` - Cambiar ocupación
- `POST /parking/{pid}/config` - Configurar parking
- `POST /parking/{pid}/message` - Enviar mensajes
- `GET /parking/{pid}/statistics` - Estadísticas detalladas
- `GET /parking/{pid}/history` - Historial de ocupación

### **Endpoints de Panel (Acceso por Asignación)**
- `POST /panel/{panel_id}/message` - Enviar mensajes
- `PUT /panel/{panel_id}/type` - Cambiar tipo de panel

### **Endpoints de Autenticación (Requieren Login)**
- `DELETE /auth/user` - Eliminar usuario propio
- `PUT /auth/password` - Cambiar contraseña
- `GET /auth/permissions` - Obtener permisos
- `POST /auth/assign` - Asignar recursos
- `GET /user/parkings` - Parkings del usuario
- `GET /user/parking/{pid}` - Parking específico del usuario
- `GET /logs/activity` - Logs de actividad
- `GET /logs/panels` - Logs de paneles

## Endpoints Públicos (Sin Autenticación)

### **Información General**
- `GET /parkings` - Lista básica de parkings
- `GET /parkings/status` - Estado general de parkings
- `GET /parking/{pid}` - Información básica de parking
- `GET /panels` - Lista de paneles
- `GET /panel-types` - Tipos de paneles
- `GET /statistics` - Estadísticas generales

### **Programaciones (Lectura)**
- `GET /schedules` - Lista de programaciones
- `GET /schedules/{id}` - Detalles de programación
- `GET /parking/{pid}/schedules` - Programaciones de parking
- `GET /parking/{pid}/active-schedules` - Programaciones activas

### **Cámaras y Logs**
- `GET /camera/logs` - Logs de cámaras
- `GET /camera/logs/stats` - Estadísticas de cámaras
- `GET /parking/{pid}/cameras` - Cámaras de parking
- `GET /cameras/status` - Estado de cámaras

### **Operaciones de Sistema**
- `POST /auth/register` - Registro de usuarios
- `POST /auth/login` - Login de usuarios
- `POST /panel/{ip}/message` - Mensaje por IP (legacy)
- `POST /panel/{panel_id}/test` - Prueba de panel
- `PUT /access/{access_id}/line` - Configurar línea de cámara
- `POST /panels/verify` - Verificar paneles

- `POST /schedules/{id}/toggle` - Activar/desactivar

- `GET /parking/{pid}/hourly-statistics` - Estadísticas por hora

### **Endpoints de Mensajes**
- `GET /parking/{pid}/message` - Obtener mensajes programados
- `DELETE /parking/{pid}/message` - Eliminar mensajes programados

## Justificación de Decisiones

### **Endpoints Protegidos**
- **Modificación de datos**: Todos los endpoints que modifican ocupación, configuración o envían mensajes están protegidos
- **Datos sensibles**: Estadísticas detalladas e historial requieren autenticación
- **Administración**: Gestión de usuarios y programaciones solo para superadmin

### **Endpoints Públicos**
- **Información básica**: Listas y estados generales para funcionalidad básica
- **Lectura de programaciones**: Permite ver programaciones sin modificar
- **Logs de cámaras**: Información de diagnóstico del sistema
- **Registro/Login**: Necesarios para el acceso inicial

### **Endpoints Pendientes**
- **Programaciones**: Requieren análisis de permisos por parking
- **Estadísticas por hora**: Podrían necesitar protección adicional
- **Mensajes programados**: Requieren verificación de permisos
