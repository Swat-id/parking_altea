# T2.3 - Implementación de Endpoints de Administración de Usuarios

## Resumen de Implementación

Se han implementado 7 endpoints de administración de usuarios en `src/api_server.py` que permiten a los superadmin gestionar usuarios del sistema de forma completa.

## Endpoints Implementados

### 1. `GET /admin/users`

**Propósito**: Listar todos los usuarios del sistema con sus asignaciones.

**Permisos**: Solo superadmin

**Respuesta**:
```json
{
  "success": true,
  "users": [
    {
      "id": 1,
      "name": "Admin User",
      "email": "admin@test.com",
      "role": "superadmin",
      "is_active": true,
      "created_at": "2025-01-27T10:00:00",
      "parking_ids": [1, 2],
      "panel_ids": [1],
      "access_ids": []
    }
  ],
  "total": 1
}
```

### 2. `POST /admin/users`

**Propósito**: Crear un nuevo usuario.

**Permisos**: Solo superadmin

**Body**:
```json
{
  "name": "Nuevo Usuario",
  "email": "nuevo@test.com",
  "password": "password123",
  "role": "user"
}
```

**Respuesta**:
```json
{
  "success": true,
  "user": {
    "id": 2,
    "name": "Nuevo Usuario",
    "email": "nuevo@test.com",
    "role": "user",
    "created_at": "2025-01-27T10:00:00"
  }
}
```

### 3. `GET /admin/users/{user_id}`

**Propósito**: Obtener detalles completos de un usuario específico.

**Permisos**: Solo superadmin

**Respuesta**:
```json
{
  "success": true,
  "user": {
    "id": 1,
    "name": "Admin User",
    "email": "admin@test.com",
    "role": "superadmin",
    "is_active": true,
    "created_at": "2025-01-27T10:00:00",
    "parkings": [
      {
        "id": 1,
        "name": "Parking Centro",
        "address": "Calle Principal 123"
      }
    ],
    "panels": [
      {
        "id": 1,
        "ip": "192.168.1.100",
        "name": "Panel Principal"
      }
    ],
    "accesses": [
      {
        "id": 1,
        "name": "Cámara Entrada",
        "line": 1
      }
    ]
  }
}
```

### 4. `POST /admin/users/{user_id}/assign`

**Propósito**: Asignar recursos (parkings, paneles, cámaras) a un usuario.

**Permisos**: Solo superadmin

**Body**:
```json
{
  "parking_ids": [1, 2],
  "panel_ids": [1, 3],
  "access_ids": [1, 2]
}
```

**Respuesta**:
```json
{
  "success": true,
  "message": "Recursos asignados correctamente"
}
```

### 5. `DELETE /admin/users/{user_id}`

**Propósito**: Eliminar (desactivar) un usuario.

**Permisos**: Solo superadmin

**Validaciones**:
- No se puede eliminar a sí mismo
- El usuario debe existir

**Respuesta**:
```json
{
  "success": true,
  "message": "Usuario eliminado correctamente"
}
```

### 6. `PUT /admin/users/{user_id}/role`

**Propósito**: Actualizar el rol de un usuario.

**Permisos**: Solo superadmin

**Body**:
```json
{
  "role": "superadmin"
}
```

**Validaciones**:
- No se puede cambiar su propio rol
- Solo roles válidos: 'superadmin', 'user'

**Respuesta**:
```json
{
  "success": true,
  "message": "Rol actualizado de user a superadmin",
  "user": {
    "id": 1,
    "name": "Admin User",
    "email": "admin@test.com",
    "role": "superadmin"
  }
}
```

### 7. `POST /admin/users/{user_id}/toggle`

**Propósito**: Activar/desactivar un usuario.

**Permisos**: Solo superadmin

**Validaciones**:
- No se puede desactivar a sí mismo

**Respuesta**:
```json
{
  "success": true,
  "message": "Usuario desactivado correctamente",
  "user": {
    "id": 1,
    "name": "Admin User",
    "email": "admin@test.com",
    "role": "superadmin",
    "is_active": false
  }
}
```

## Características Técnicas

### Seguridad

- Todos los endpoints están protegidos con `@require_superadmin`
- Validaciones para evitar auto-eliminación y auto-desactivación
- Validación de roles permitidos
- Manejo seguro de sesiones de base de datos

### Manejo de Datos

- Consultas optimizadas con JOINs para obtener detalles completos
- Formateo consistente de fechas en ISO format
- Respuestas estructuradas con campos `success` y `message`
- Manejo de errores con códigos HTTP apropiados

### Logging

- Registro de todas las acciones administrativas
- Información detallada de cambios de estado
- Trazabilidad de operaciones por superadmin
