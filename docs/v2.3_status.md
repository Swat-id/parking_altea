## 🏗️ Arquitectura Técnica

### Backend (Python Flask)
```python
# Modo sin login implementado en auth.py
def require_auth(f):
    @wraps(f)
    def decorated_function(*args, **kwargs):
        if not token:
            # Asignar usuario superadmin por defecto
            user = db_session.query(User).filter(User.email == 'info@swat-id.com').first()
            request.user_data = {
                "user_id": user.id,
                "email": user.email,
                "name": user.name
            }
        return f(*args, **kwargs)
```
