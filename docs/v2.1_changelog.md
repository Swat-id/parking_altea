# Parking Altea - Versión v2.1

## Nuevas Funcionalidades

### Sistema de Usuarios y Autenticación

#### Clase Usuario
- **Nombre**: Campo obligatorio para identificar al usuario
- **Correo electrónico**: Campo único y obligatorio para autenticación
- **Contraseña**: Hash seguro usando bcrypt
- **ID**: Identificador único para relaciones

#### Tablas Intermedias
- **user_parkings**: Relaciona usuarios con aparcamientos
- **user_panels**: Relaciona usuarios con paneles
- Permite asignar múltiples parkings/paneles a un usuario
- Evita modificar tablas existentes

### API de Autenticación

#### Endpoints de Usuario
- `POST /auth/register` - Crear nuevo usuario
- `POST /auth/login` - Autenticar y obtener token JWT
- `GET /auth/profile` - Obtener perfil del usuario autenticado
- `DELETE /auth/users/{user_id}` - Eliminar usuario (solo propio)

#### Endpoints de Asignación
- `GET /auth/users/{user_id}/parkings` - Obtener parkings del usuario
- `GET /auth/users/{user_id}/panels` - Obtener paneles del usuario
- `POST /auth/assign/parking` - Asignar parking a usuario
- `POST /auth/assign/panel` - Asignar panel a usuario

### Seguridad
- **JWT Tokens**: Autenticación basada en tokens
- **bcrypt**: Hash seguro de contraseñas
- **Autorización**: Usuarios solo acceden a sus recursos asignados
- **Protección de rutas**: Todas las rutas existentes ahora requieren autenticación

## Uso de la API

### Registro de Usuario
```bash
curl -X POST http://localhost:6001/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Usuario Ejemplo",
    "email": "usuario@ejemplo.com",
    "password": "contraseña123"
  }'
```

### Login
```bash
curl -X POST http://localhost:6001/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "usuario@ejemplo.com",
    "password": "contraseña123"
  }'
```

### Acceso a Recursos Protegidos
```bash
curl -X GET http://localhost:6001/parkings \
  -H "Authorization: Bearer <token_jwt>"
```

## Instalación y Configuración

1. Instalar nuevas dependencias:
```bash
pip install -r requirements.txt
```

2. Ejecutar el servidor API:
```bash
python src/api_server.py
```

3. Crear usuarios iniciales:
```bash
python src/create_initial_users.py
```

## Notas de Migración

- Las tablas existentes no se modifican
- Se crean nuevas tablas para usuarios y relaciones
- Las rutas existentes ahora requieren autenticación
- Los usuarios solo pueden acceder a recursos asignados
