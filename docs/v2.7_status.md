## 🚨 Correcciones Críticas

### v2.7.1 - Corrección de Cálculo de Deltas

**Problema**: Los contadores de cámaras reportaban incrementos incorrectos (ej: 408→409 reportaba +3 en lugar de +1)

**Causa**: En la función `detect_camera_reset()` del archivo `camera_server.py`, la lógica para ajustar el contador anterior era incorrecta:

```python
# LÍNEA PROBLEMÁTICA (ANTES)
adjusted_previous_in = 0 if new_in <= previous_in else previous_in
```

**Solución**: Usar siempre cero como contador anterior en caso de reset:

```python
# LÍNEA CORREGIDA (DESPUÉS)
adjusted_previous_in = 0
```

**Impacto**: 
- ✅ Cálculos de ocupación ahora son precisos
- ✅ Deltas reportados correctamente
- ✅ Logs detallados para diagnóstico
- ✅ Validación con tests específicos
